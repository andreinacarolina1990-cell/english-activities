💡 Grammar Reference

Comparative (than) Short adj: add -er → bigger, taller
Long adj: use more → more difficult
Superlative (the …est / most) Short adj: add -est → the biggest
Long adj: use the most → the most difficult
Spelling rules CVC ending: double consonant → big → bigger
-y ending: change to -i → funny → funniest
Key signals "than" → comparative
"the … I've ever …" → superlative
